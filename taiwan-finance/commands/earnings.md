# 財報分析指令（台股）

產出一份專業的台股研究「財報更新報告」，分析某一季的營運結果。全程使用**繁體中文（台灣用語）**，遵守 `taiwan-finance-context` 技能規則（新台幣億／兆、T-IFRS、台股代號、結尾免責）。

## 工作流程

### 步驟 1：蒐集資訊

從輸入解析出：
- 公司名稱或股票代號（例：台積電 2330）
- 季別（例：2024 Q3、114 年第一季）

若未提供就詢問：
- 「你想分析哪一家公司的財報？」
- 「哪一季？（例：2024 Q3）」

### 步驟 2：確認資料時效

**重要**：開始前先確認你拿到的是最新資料：
1. 用 **TWSE MCP（`twstock`）** 查該公司最新一季的綜合損益表是否已公布。
2. 確認財報期間正確（季報 / 半年報 / 年報）。
3. 法說會逐字稿資料源沒有 → 請老師從**公開資訊觀測站（MOPS, mops.twse.com.tw）**下載後貼進對話。
4. 若資料較舊，告知使用者並改抓最新。

### 步驟 3：載入財報分析技能

用 `skill: "earnings-analysis"` 製作報告：

1. **資料蒐集**（以台灣來源為主）：
   - 財報（綜合損益表、資產負債表）→ TWSE MCP / MOPS
   - 季報 / 年報原始檔 → MOPS（取代美國的 SEC EDGAR）
   - 法說會逐字稿 / 簡報 → 老師從 MOPS 貼上
   - 月營收 → TWSE MCP
   - 市場共識預估 → 台股若無公開共識資料，標 `[需查證]`，不可編造

2. **優於／低於預期分析（Beat/Miss）**：
   - 營收 vs. 共識：高出／低於 X 億元或 X%
   - EPS vs. 共識：高出／低於 X 元或 X%
   - 各部門 / 各產品線表現 vs. 預期
   - 解釋「為什麼」結果有差異

3. **關鍵指標分析**：
   - 營收按部門 / 地區拆解
   - 利潤率趨勢（毛利率、營業利益率、淨利率）
   - 財測（guidance）：上調／維持／下調
   - 更新後的前瞻預估

4. **產生圖表（8～12 張）**：
   - 各季營收走勢
   - 各季 EPS 走勢
   - 利潤率趨勢
   - 各部門營收
   - Beat/Miss 彙總
   - 預估調整
   - 估值圖

5. **製作報告（8～12 頁）**：
   - 第 1 頁：摘要，含評等與目標價
   - 第 2-3 頁：詳細結果分析
   - 第 4-5 頁：關鍵指標與財測
   - 第 6-7 頁：更新後的投資論點
   - 第 8-10 頁：估值與預估
   - 資料來源區（附可點擊連結）

### 步驟 4：交付產出

提供：
1. **DOCX 報告** — 8～12 頁財報更新
2. **摘要**，重點標出：
   - 關鍵指標的優於／低於預期
   - 財測變化
   - 對投資論點的影響（正面／負面／中性）

## 報告結構參考

```
第 1 頁：財報摘要
┌─────────────────────────────────────────────────────────────────┐
│ 台積電（2330）2024 Q3 財報更新                                   │
│ 評等：（教學示範用，非投資建議） | 目標價：NT$XXX（前次 NT$XXX）│
├─────────────────────────────────────────────────────────────────┤
│ 重點摘要                                                         │
│ • 營收高出共識 X%，主因 [某部門] 表現強勁                        │
│ • EPS 高出 X.XX 元，受惠利潤率擴張                               │
│ • 全年財測上調至 X.XX–X.XX 元（前次 X.XX–X.XX 元）              │
│ • 投資論點不變                                                   │
├─────────────────────────────────────────────────────────────────┤
│ 結果快照                                                         │
│ ┌─────────────┬──────────┬──────────┬──────────┐               │
│ │ 指標        │ 實際     │ 共識     │ 優於/低於│               │
│ │ 營收        │ X.XX 億  │ X.XX 億  │ +X.X%    │               │
│ │ EPS         │ X.XX 元  │ X.XX 元  │ +X.XX 元 │               │
│ │ 毛利率      │ XX.X%    │ XX.X%    │ +XX bp   │               │
│ └─────────────┴──────────┴──────────┴──────────┘               │
└─────────────────────────────────────────────────────────────────┘

第 2-3 頁：詳細結果（各部門分析、地區拆解、優於/低於預期的主因）
第 4-5 頁：指標與財測（利潤率分析、全年財測比較、各季預估更新）
第 6-7 頁：論點更新（有什麼改變、風險與催化事件、投資建議）
第 8-10 頁：估值（如有重大變化則更新 DCF/同業比較、目標價依據、情境分析）

資料來源區（附可點擊連結）：
- 財報：MOPS [連結]
- 季報 / 年報：MOPS [連結]
- 法說會逐字稿：[連結]
- 共識預估：[來源與日期]
```

## 品質檢查清單

交付前確認：
- [ ] 財報是最新一季（非過期）
- [ ] 優於／低於預期都有具體數字
- [ ] 圖表齊全（8～12 張）
- [ ] 資料來源區附可點擊連結
- [ ] 每個數字／表格都有來源引用；查不到的標 `[需查證]`
- [ ] 財測變化清楚記錄
- [ ] 評等與目標價開頭就講清楚，並標「教學示範、非投資建議」
- [ ] 8～12 頁，3,000–5,000 字
- [ ] 結尾標註：「※ 本內容僅供學術討論與教學示範，非投資建議。」
