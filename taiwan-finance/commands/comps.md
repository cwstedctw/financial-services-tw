# 同業比較分析指令（台股）

建立機構等級的同業比較分析（comparable company analysis），含營運指標、評價倍數與統計基準。全程**繁體中文**，遵守 `taiwan-finance-context` 規則。

> 白話：同業比較就是「找幾家差不多的公司排在一起，看這家是貴還是便宜、賺得多不多」。

## 工作流程

### 步驟 1：取得公司資訊

若有提供公司名稱或代號就用它，否則詢問：
- 「你想分析哪一家公司？」（例：台積電 2330）

### 步驟 2：載入同業比較技能

用 `skill: "comps-analysis"` 建立分析：

1. **釐清分析目的**：
   - 「主要想回答什麼？」（估值、效率、成長性比較）
   - 「給誰看？」（課堂、報告、快速參考）
   - 「有沒有偏好的格式或範本？」

2. **挑選同業組（4～6 家可比公司）**：
   - 類似的商業模式
   - 類似的規模／市值區間
   - 同產業
   - 地區可比（以台股為主；沒指定就用 `taiwan-finance-context` 預設同業組）

3. **取得資料**（優先用 `twstock` TWSE MCP）：
   - 營運指標：營收、成長率、毛利率、EBITDA、EBITDA 利潤率
   - 評價：市值、企業價值（EV）、EV/營收、EV/EBITDA、本益比（P/E）
   - 依產業加上額外指標（見下方產業別指標）
   - 查不到的數字標 `[需查證]`，不可編造

4. **建立分析**：
   - 營運統計區：各公司數據 + 統計（最大、75 分位、中位、25 分位、最小）
   - 評價倍數區：相同統計摘要
   - 註解與方法說明

### 步驟 3：產出 Excel

產生 Excel 檔，含：
- 標頭（分析標題、公司、日期、單位＝新台幣百萬／億元）
- 營運統計與財務指標區
- 評價倍數區
- 每個指標的統計摘要
- 註解區（記錄來源與方法）

### 步驟 4：交付產出

提供：
1. **Excel 檔（.xlsx）** — 同業比較分析
2. **摘要**，重點標出：
   - 同業組挑選理由
   - 關鍵洞察（誰享有溢價／誰被低估）
   - 中位數倍數供參考

## 產業別補充指標

| 產業 | 額外指標 |
|------|---------|
| 半導體 | 產能利用率、先進製程占比、資本支出/營收 |
| 電子代工/組裝 | 出貨量、營益率、存貨周轉 |
| 金融 | ROE、ROA、淨值比、逾放比 |
| 傳產/塑化鋼鐵 | 資產周轉率、產能利用率、資本支出/營收 |
| 電信/民生 | 同店銷售、ARPU、現金殖利率 |

## 品質檢查清單

交付前確認：
- [ ] 4～6 家真正可比的公司
- [ ] 期間一致（都用近 12 個月或都用全年）
- [ ] 所有公式都參照儲存格（不寫死數值）
- [ ] 寫死的輸入都在儲存格註解標來源
- [ ] 統計含最大、75 分位、中位、25 分位、最小
- [ ] 註解區記錄來源與方法
- [ ] 藍色＝輸入，黑色＝公式
- [ ] 合理性檢查通過（利潤率合理、倍數合理）
- [ ] 結尾標註：「※ 本內容僅供學術討論與教學示範，非投資建議。」
