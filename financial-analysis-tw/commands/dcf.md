# DCF 估值指令（台股）

建立機構等級的 DCF（現金流折現）模型，並用同業比較來校準估值區間。全程**繁體中文**，遵守 `taiwan-finance-context` 規則。

> 白話：DCF 是「把公司未來每年會賺到的現金，用一個折現率換算成今天值多少錢」，加總起來就是公司的合理價值。

## 工作流程

### 步驟 1：取得公司資訊

若有提供公司名稱或代號就用它，否則詢問：
- 「你想估值哪一家公司？」（例：台積電 2330）

### 步驟 2：先做同業比較

**先載入 comps-analysis 技能**建立同業比較：

用 `skill: "comps-analysis"`：
1. 挑 4～6 家可比上市公司
2. 取得營運指標（營收、EBITDA、利潤率、成長率）
3. 取得評價倍數（EV/營收、EV/EBITDA、本益比）
4. 算統計摘要（中位數、25／75 分位）

**要從同業比較抓出的關鍵數字：**
- 中位 EV/EBITDA 倍數 → 用來設定 DCF 的終值出場倍數
- 中位 EV/營收倍數 → 對 DCF 結果做合理性檢查
- 同業成長率 → 營收預估的基準
- 同業利潤率 → 利潤率假設的基準

### 步驟 3：建立 DCF 模型

**載入 dcf-model 技能**建構估值：

用 `skill: "dcf-model"`：
1. 蒐集歷史財報與市場資料（TWSE MCP；多年期不足時用 FinMind）
2. 建立營收預估（保守／基本／樂觀三案）
3. 模擬營業費用與自由現金流（FCF）
4. 用 CAPM 算加權平均資金成本（WACC）
5. 折現現金流並計算終值
6. 橋接到股東權益價值與每股合理價

**用同業比較校準 DCF 假設：**

| 同業比較產出 | DCF 輸入 |
|--------------|----------|
| 同業中位 EV/EBITDA | 終值出場倍數區間 |
| 同業 25–75 分位 EV/EBITDA | 敏感度分析區間 |
| 同業中位成長率 | 營收假設基準 |
| 同業中位 EBITDA 利潤率 | 終值年目標利潤率 |
| 同業中位本益比 | 對照 DCF 隱含本益比 |

### 步驟 4：交叉檢查估值

DCF 完成後驗證：
1. **DCF 隱含 EV/EBITDA** vs 同業中位
   - 若 DCF 隱含 25 倍但同業只有 12 倍，要查清楚為什麼
2. **DCF 隱含本益比** vs 同業中位
3. **終值佔企業價值比重**（一般應在 50–70%）
4. **估值隱含的成長率** vs 同業成長率

### 步驟 5：交付產出

提供：
1. **同業比較試算表（.xlsx）** — 同業評價倍數
2. **DCF 模型（.xlsx）**，含：
   - 保守／基本／樂觀情境
   - 敏感度分析表（WACC vs 終值成長率等）
   - 估值彙總與隱含上漲／下跌空間
3. **摘要**，說明：
   - 關鍵估值驅動因素
   - 同業比較如何校準分析
   - 要留意的風險與敏感度

## 範例產出摘要

```
估值彙總：台積電（2330）

同業比較分析：
- 同業組：[4～6 家台股]
- 中位 EV/EBITDA：12.5 倍（區間 10.2 – 15.8 倍）
- 中位 EV/營收：3.2 倍（區間 2.1 – 4.5 倍）

DCF 估值（基本情境）：
- 隱含每股合理價：NT$ XX.XX
- 目前股價：NT$ YY.YY
- 隱含上漲空間：+XX%

估值交叉檢查：
- DCF 隱含 EV/EBITDA：13.2 倍（vs 同業中位 12.5 倍）
- DCF 隱含本益比：22.4 倍（vs 同業中位 20.1 倍）
- 終值：佔企業價值 62%（在正常範圍內）

關鍵假設：
- 營收年複合成長率（CAGR）：X%（vs 同業中位 X%）
- 終值 EBITDA 利潤率：X%（vs 同業中位 X%）
- WACC：X.X%
- 終值成長率：X.X%
```
